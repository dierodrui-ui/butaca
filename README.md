# Butaca

App IPTV para Google TV / Android TV (Xiaomi Mi TV Box S), compatible con servidores Xtream Codes.

## Instalar o actualizar desde Downloader

En la app **Downloader** de la tele, escribe:

```
https://github.com/dierodrui-ui/butaca/releases/latest/download/butaca.apk
```

Cada vez que se sube un cambio, GitHub compila una versión nueva automáticamente (pestaña *Actions*) y la publica en *Releases*. Al instalarla encima de la anterior se conservan las carpetas, los favoritos y el progreso.
